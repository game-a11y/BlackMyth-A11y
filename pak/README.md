# pak - .pak 格式 Mod

此目录下的项目用于生成 **.pak 格式** 的 Mod 文件。
pak 格式的 MOD 可以与其他类型的 MOD 联用。

.pak 是虚幻引擎的打包格式，游戏通过 `b1/Content/Paks/` 加载此格式的 Mod。
