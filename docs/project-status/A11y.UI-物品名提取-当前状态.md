# A11y.UI 装备/背包物品名提取 — 当前状态

## 已完成

### EquipItem / GearItem (装备槽 / 珍玩槽)
- **数据源**: `GSG.GamePlayer.Actor.Wear.EquipList.ValueList` (List<DSWearEquip>)
- **映射**: slot FName "BI_EquipSlotItem_5" → ParseSlotIndex → EEquipSlotType → EquipPosition
- **名称解析**: `GameDBRuntime.GetEquipDesc(w.Id).EquipName.ToFText().ToString()`
- **空槽检测**: EquipList 无匹配 → 输出 "装备 (空)" / "老葫芦 (空)"
- **状态**: ✅ 正常工作

### QuickItem (随身之物)
- **数据源**: `GSG.GamePlayer.Actor.Wear.ShortcutsList.ValueList` (List<DSShortcutItem>)
- **映射**: GetQuickItemPosition (控件树同级序号 - 1) → Position → ShortcutsList 匹配
- **名称解析**: `GameDBRuntime.GetItemDesc(s.ItemId).Name.ToFText().ToString()`
- **空槽检测**: ShortcutsList 无匹配 → 输出 "随身之物 (空)"
- **状态**: ✅ 正常工作（控件树 pos-1 对齐）

- `raw.ToFText().ToString()` — 解析本地化 key
- 占位符过滤: "名字名字"
- Ruby 注音标签剥离: Regex `<[^>]+>`

### FindTextByName (文本类型兼容)

```
