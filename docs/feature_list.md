# 功能列表与测试要点

适用于《黑神话：悟空》无障碍 Mod。本文档供用户和测试人员使用。

---

## 一、场景切换检测

Mod 能识别游戏当前处于哪个阶段，并在日志中输出切换消息。

### 可识别的场景

| 场景 | 日志输出 |
|---|---|
| 启动/加载中 | `场景切换: Unknown → Loading` |
| 主菜单 (StartGame) | `场景切换: Loading → MainMenu` |
| 游戏中 (InBattleStandAlone) | `场景切换: Loading → InGame` |
| 登录界面 | `UI打开: LoginNotice` |
| 打开设置 | `UI打开: Setting (ID=33)` |
| 打开土地庙 | `UI打开: ShrineMain (ID=7)` |
| 打开背包 | `UI打开: BagMain (ID=15)` |
| 打开装备 | `UI打开: EquipMain (ID=14)` |
| 死亡/战败 | `UI打开: Death (ID=9)` |
| 打开地图 | `UI打开: MapTips (ID=32)` |
| 暂停游戏 | `SetGamePause: OpenUI → 暂停` |

### 快捷键
`Ctrl + D1` — 打印当前所处的场景和可见 UI 页面摘要。

### 测试确认
- [ ] 从启动到主菜单，日志是否输出正确的场景切换
- [ ] 进入游戏后日志是否显示 `InGame`
- [ ] 打开各个菜单（设置、背包、装备等），是否有对应 `UI打开` 日志
- [ ] 关闭菜单后是否有 `UI关闭` 日志
- [ ] 传送后是否输出 `LeavingMap` / `PreLoadMap`
- [ ] Ctrl+D1 是否能显示当前状态的完整摘要

## 二、UI 按钮朗读

当鼠标悬停或键盘/手柄导航到按钮时，读出按钮上的文字。

### 已覆盖的界面

| 界面 | 能读出的内容 | 示例 |
|---|---|---|
| 主菜单 | 继续游戏、新游戏、载入游戏、小曲、设置、退出 | `继续游戏 (GSID=20)` |
| 设置 — 标签页 | 控制器、键盘与鼠标、游戏、视角、语言、显示、画质、声音、辅助设置、退出游戏 | `控制器 (GSID=68)` |
| 设置 — 开关 | 当前值（开启/关闭） | `开启 (GSID=114)` |
| 设置 — 滑块 | 当前数值 | `50 (GSID=181)` |
| 确认对话框 | 确定、取消 | `确定 (GSID=299)` |
| 土地庙菜单 | 各菜单项 | |
| 技能面板 | 技能名称 | |

### 日志输出格式
```
[UI.Focus] 聚焦 继续游戏 (GSID=20)     ← 按钮获得焦点
[TTS] 继续游戏 [打断]                    ← 屏幕朗读输出
[UI.Focus] 失焦 WidgetID=20             ← 按钮失去焦点
[UI.Click] 点击 WidgetID=28            ← 按钮被点击
[UI.KeyUp] 按键 WidgetID=70            ← 键盘操作
```

### 测试确认
- [ ] 鼠标悬停主菜单各按钮，是否能正确读出：继续游戏、新游戏、载入游戏、小曲、设置、退出
- [ ] 进入设置页，各标签页是否正确读出
- [ ] 设置页内的开关/滑块/下拉菜单，能否读出当前值
- [ ] 确认对话框的确定/取消能否读出
- [ ] 土地庙菜单能否读出各选项
- [ ] 键盘/手柄导航按钮时能否正确读出
- [ ] 所有按钮点击是否有 `[UI.Click]` 日志
- [ ] 键盘操作是否有 `[UI.KeyUp]` 日志

## 四、已知限制

| 限制 | 说明 |
|---|---|
| 设置项读取不完全 | 部分设置项只能读到值（如“开启”），读不到控件名称（如“控制器类型”） |
| 需要 JIT 模式 | `b1cs.ini` 文件中需设置 `EnableJit=1`，否则按钮朗读等功能不工作 |
| 屏幕朗读暂未接入 | 当前 `[TTS]` 仅输出到日志，尚未调用读屏软件 |

---

## 快速测试流程

1. 确认 `CSharpLoader/b1cs.ini` 中有 `EnableJit=1`
2. 启动游戏，打开控制台窗口（`b1cs.ini` 中 `Console=true`）
3. 依次操作：进入主菜单 → 逐个查看按钮 → 进入设置 → 查看各设置项 → 加载存档进入游戏 → 传送到其他区域
4. 观察日志中的 `[UI.Focus]`、`[UI.Click]`、`场景切换` 等消息
5. 按 `Ctrl + D1` 查看当前场景状态
