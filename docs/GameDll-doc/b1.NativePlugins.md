## 通用基类层次结构

项目中 Unreal Engine 类型的前缀约定:

| 前缀 | 类型 | 说明 |
|------|------|------|
| `A` | Actor 类 | 可放置在世界中的对象 (如 `AAkAmbientSound`) |
| `U` | Object/组件/其他类 | 非 Actor UObject 派生类 (如 `UAkComponent`) |
| `I` | 接口 | Unreal Interface (如 `IDonNavigator`) |
| `F` | 结构体/委托 | UStruct 或委托类型 (如 `FAkExternalSourceInfo`) |
| `E` | 枚举 | UEnum (如 `EAkResult`) |

派生链示例:
- `UAkComponent` extends `UAkGameObject` extends `USceneComponent` extends `UActorComponent` extends `UObject`
- `ACalliopeLevelSequenceActor` extends `ALevelSequenceActor` extends `AActor`
- `UHoudiniAssetComponent` extends `UPrimitiveComponent` implements `IHoudiniAssetStateEvents`
